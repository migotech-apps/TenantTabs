# TenantTabs by Migotech

TenantTabs turns Firefox's new-tab page into a searchable container chooser.
Choose a container, then type straight into the address bar.

This repository hosts **public documentation, support resources and third-party compliance materials**.
TenantTabs' proprietary extension source code is not included.

## Features

- Native Firefox container management and container groups.
- Favourites and recently used containers.
- Smart website rules and temporary containers.
- Manual configuration backup and restore.
- Optional paid Pro: bulk management, smart tab placement, group naming
  customisation and automatic backups.

Firefox **148.0 or later** is required. **1.0.0** is the current published version,
[available on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/tenanttabs/). Pro activates inside
the public Free extension; a separate Pro download is not required.
