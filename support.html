TenantTabs support

Report reproducible bugs through GitHub Issues. Email private billing, licence and privacy enquiries to tenanttabs@m.migotech.net.

Requirements

This release requires Firefox 148.0 or later. Firefox versions below 148 are not supported. TenantTabs replaces the new-tab page with a container chooser. Select a container option, then type into Firefox's address bar.

Before reporting a problem

Check that Firefox meets the minimum version and TenantTabs is enabled. If another extension controls your new-tab page, review that setting. For website routing, check the rule and its selected container. Save your work before restarting Firefox; do not clear storage or delete containers as a first troubleshooting step.

Record your Firefox and TenantTabs versions, operating system, steps to reproduce, expected result and actual result. Say whether the problem concerns container selection, website rules, backups or paid activation. Use fictional container and website examples where possible. Redact screenshots before sharing.

Protect private information

GitHub Issues are public. Never post passwords, API keys, payment-card details, full billing/login links, browser profiles or unredacted backups. Backups can contain private names and website rules. A support request does not normally need a complete backup. Send account-specific information by email, sharing only what is necessary.

Paid activation

The public TenantTabs extension includes Free features and optional paid Pro activation; a separate Pro download is not required. In License & billing, paid activation requires Allow licensing connections to ExtensionPay. Use Sign in / restore purchase to recover an existing purchase and Refresh license to request verification. Free features remain available when licensing connections are disabled.

Subscription management

After checkout or email sign-in, return to License & billing and refresh verification. Check the inbox used for the original purchase, including spam folders. Previously verified access can continue offline for up to 24 hours in the current browser session; restarting requires fresh verification. If recovery fails, email support rather than buying again.

Use Manage subscription when available to open the provider's account page. Removing TenantTabs does not cancel recurring billing. Do not make another purchase solely to resolve a sign-in or activation problem.

Backups and updates

For payment questions, refer to the applicable terms displayed during hosted checkout or account management, or email us privately. This page does not establish additional refund terms.

Use TenantTabs' manual backup and restore controls to save or import configuration. Keep a current backup before restoring older settings and review import warnings. Pro automatic backups require verified paid access. Backups contain configuration, not website cookies, logged-in sessions or paid account credentials.

Keep your own backup files safe. Restore does not transfer a paid licence or activate paid features. An update may remain pending until Firefox restarts to protect untouched destination tabs; save other browser work before quitting.

Contact

Migotech: tenanttabs@m.migotech.net. Support correspondence is deleted 12 months after the last interaction unless longer retention is necessary for an unresolved dispute or legal obligation. See the privacy policy for details.
